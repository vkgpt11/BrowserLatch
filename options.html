Supporting content

Allowed websites may need scripts, video, images, and API calls from other domains. Compatibility mode permits these requests from an allowed page. Turn it off to block unlisted requests; some websites may stop working.

Embedded sign-in and payment pages from unlisted domains stay blocked in either setting. Add a provider domain to Allowed websites if needed; this also allows visiting that provider directly.

How to keep settings protected
The password makes changes harder, but someone who can manage browser extensions can turn BrowseLatch off or remove it. For stronger protection, use a child account and browser settings managed by an adult.
